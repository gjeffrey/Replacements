# App icon

The current 0.3.0 icon and its generation prompts are documented in [Icon 0.3.0](ICON-v030.md). The prompts below describe the earlier 0.2 icon.

Generated with the built-in image generation tool, then packaged into macOS icon sizes with alpha preserved. The image is an original mark inspired by the restraint of native Apple utilities; no Apple logo or existing app icon was copied.

Asset: `Resources/AppIcon.png`
Packaged icon: `Resources/AppIcon.icns`

## Initial prompt

Use case: logo-brand. Asset type: final macOS application icon for a native text-replacement utility named Replacements. Create one beautiful, extremely simple, original icon with the visual restraint and craftsmanship of a first-party Apple utility, without copying an existing app icon or using the Apple logo. Square 1024 by 1024 canvas. A large centered rounded-square tile, aligned straight-on, with a softly luminous pale sky-blue to rich cobalt-blue gradient, very subtle polished depth, crisp edges and ample breathing room. On the tile is a single bold, optically balanced white symbol that communicates turning a short bit of text into a longer phrase: one short rounded horizontal text stroke at upper left, a clean rightward expansion arrow at the center, and two longer rounded horizontal text strokes at lower right, combined as one coherent compact mark. Use only these three ideas, integrated into a simple readable glyph. The silhouette must read clearly at 32 pixels. Refined, calm, tactile, timeless; no busy decoration, no glass bubbles, no extraneous sparkles, no realistic keyboard, no labels, no words, no letters, no watermark, no border framing the canvas. The rounded tile should fill about 87 percent of the canvas, leaving a genuinely transparent margin outside the tile. Preserve actual alpha transparency outside the tile. No fake checkerboard.

## Refinement prompt

Edit this macOS app icon. Preserve the blue rounded-square tile, the white short text stroke, the white curved right arrow, the two white longer text strokes, their exact arrangement, and the restrained polished appearance. Change only the tile's outer contour and transparency: make the rounded-square silhouette mathematically smooth and perfectly clean, with subtle high-quality antialiasing; remove every stray white fleck, turquoise speck, edge halo, scratch and pixel artifact outside the tile, especially along the top edge. Everything outside the rounded-square tile must be genuinely transparent with clean alpha. No additional elements or shadows spilling outside the shape. Keep the tile centered on a square canvas with the same proportions and padding. Deliver a production-quality application icon, readable at 32px.
